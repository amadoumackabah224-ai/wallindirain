Votre compte vendeur Nom, numéro de téléphone, mot de passe (conservé sous forme chiffrée, illisible), adresse e-mail (facultative, confirmée par un code reçu dans votre boîte), opérateur et numéro de versement (Orange Money ou MTN MoMo), référence de pièce d'identité, code de parrainage et, si vous avez été invité, le nom de votre parrain. Gérer le compte, verser l'argent sur le bon numéro, vérifier l'identité avant le premier retrait. Tant que le compte existe. À la suppression du compte, ces données sont effacées (voir « Vos droits »).
